# ⚡ AA Macro Studio v2.0

Anime Adventures Macro Automation Script with Discord Webhook, Cloud Sharing, and Telemetry.

## 🚀 วิธีการรันสคริปต์ (ทุกเครื่องใช้คำสั่งนี้)

คัดลอกคำสั่งด้านล่างไปวางใน Executor (รองรับทั้ง PC และ Mobile):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/PeeKillxa/AA_Macro/main/loader.lua?t=" .. tick()))()
```

หรือรันตรงจากไฟล์หลัก:
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/PeeKillxa/AA_Macro/main/main_v2.lua?t=" .. tick()))()
```

---

## 🔄 เมื่อแก้ไขโค้ดในคอมพิวเตอร์หลัก

1. แก้ไขไฟล์ `main_v2.lua`
2. ดับเบิลคลิกไฟล์ `push_update.bat`
3. เครื่องอื่น ๆ ที่รันคำสั่งด้านบนจะได้รับโค้ดเวอร์ชันใหม่อัตโนมัติทันที!
